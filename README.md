Welcome to **Version 2.0** of my personal portfolio website. This project showcases my skills, tools, projects, and provides a way to contact me. It has been completely rebuilt using modern web technologies for better performance, maintainability, and developer experience.

## 🚀 Features

*   **Modern Tech Stack**: Built with React 19, TypeScript, and Vite for lightning-fast development and production builds.
*   **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices.
*   **Dark Mode Support**: Built-in dark mode support using Tailwind CSS.
*   **Modular Components**: Clean and organized component structure (Header, Hero, Skills, Tools, Projects, Contact, Footer).
*   **Type Safety**: Full TypeScript support for robust and error-free code.

## 🛠️ Tech Stack

*   **Framework**: [React](https://react.dev/)
*   **Build Tool**: [Vite](https://vitejs.dev/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Package Manager**: npm

## 🏁 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Ensure you have Node.js installed on your system.

### Installation

1.  **Clone the repository**
    ```bash
    git clone <repository-url>
    cd abdulmuiz-jimoh
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

### Running Locally

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port shown in your terminal).

## 📦 Building for Production

To create a production-ready build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
